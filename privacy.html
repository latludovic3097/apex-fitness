Politique de confidentialité

Dernière mise à jour : 14 mai 2026 · Version 1.0

TL;DR : APEX Fitness fonctionne 100% local par défaut. Aucune donnée ne quitte ton appareil sauf si tu actives la sync cloud (Google sign-in). Aucune publicité, aucun tracking, aucun partage avec des tiers commerciaux. Tes données t'appartiennent — tu peux les exporter ou tout effacer à tout moment depuis l'app.

1. Qui sommes-nous ?

APEX Fitness est une application web (PWA) de tracking d'entraînement musculaire, gratuite et open-source. Elle est éditée à titre personnel par un particulier basé en France. Le code source est public sur GitHub.

Responsable du traitement : Ludovic Lat (contact : lat.ludovic@gmail.com)

2. Quelles données collectons-nous ?

2.1 Données stockées localement sur ton appareil (par défaut)

Lorsque tu utilises l'app, les données suivantes sont stockées dans le localStorage de ton navigateur — elles ne quittent jamais ton appareil :

Profil corporelSexe, âge, taille, poidsCalcul BMR / TDEE (Mifflin-St Jeor)
Historique des séancesDate, durée, exercices, poids, répétitions, RIRSuivi de progression, suggestions APRE

Données cardio / nutrition / corePesées, courses, objectifs caloriquesCalcul de macros, suivi du poids
État de session activeSets en cours, timerReprise après fermeture du navigateur

2.2 Données synchronisées dans le cloud (uniquement si tu te connectes avec Google)

Si tu actives la sync cloud via Réglages → Cloud Sync → Se connecter avec Google, les données ci-dessus sont également stockées dans Google Firestore (Google Cloud) sous ton compte Google. Ceci permet de retrouver tes données sur plusieurs appareils.

Données supplémentaires liées à l'authentification :

  • Ton adresse e-mail Google (pour identifier ton compte)
  • Ton nom d'affichage Google (optionnel, affiché dans l'app)
  • Ton identifiant utilisateur Firebase (UID)

Aucune autre donnée n'est partagée avec Google au-delà de ce qui est nécessaire à la sync.

2.3 Ce que nous NE collectons PAS

  • ❌ Localisation GPS
  • ❌ Contacts, photos, fichiers de ton appareil
  • ❌ Données de navigation (sites visités, cookies tiers, fingerprinting)
  • ❌ Données de tracking publicitaire ou analytique
  • ❌ Informations bancaires ou de paiement (l'app est gratuite)
  • ❌ Données médicales sensibles diagnostiquées

4. Base légale du traitement (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), nos traitements reposent sur :

  • Exécution du contrat (art. 6.1.b) : tes données d'entraînement sont nécessaires au fonctionnement de l'app que tu utilises
  • Consentement (art. 6.1.a) : pour la sync cloud (activée explicitement via Google sign-in)
  • Intérêt légitime (art. 6.1.f) : logs serveur Firebase pour la sécurité et la maintenance

5. Durée de conservation

  • Données locales : conservées tant que tu utilises l'app. Tu peux tout effacer via Réglages → Effacer (avec backup automatique).
  • Données cloud (Firestore) : conservées tant que ton compte Google est lié. Tu peux te déconnecter à tout moment ; les données restent dans Firestore mais peuvent être supprimées sur demande (voir §7).
  • Logs serveur Firebase : ~30 jours selon la politique Google.

6. Sécurité

  • Toutes les communications avec Firebase utilisent HTTPS (TLS 1.3).
  • Tes données dans Firestore sont protégées par des Security Rules strictes : seul toi (via ton UID authentifié) peux lire/écrire ton document. Aucun autre utilisateur n'y a accès.
  • La clé API Firebase utilisée côté client est restreinte par domaine (HTTP referrers) et par API (Identity Toolkit + Firestore uniquement).
  • Aucune donnée ne transite par un serveur tiers contrôlé par nous.

7. Tes droits (RGPD)

En tant qu'utilisateur européen, tu disposes des droits suivants :

  • Droit d'accès et de portabilité : exporte toutes tes données à tout moment via Réglages → JSON backup. Le fichier généré contient l'intégralité de ce qu'on stocke sur toi (local + cloud).
  • Droit de rectification : modifie tes données directement dans l'app (Réglages, Nutrition, etc.).
  • Droit à l'effacement (« droit à l'oubli ») : Réglages → Effacer (efface le local). Pour effacer le cloud, contacte-nous (cf. §8) ou supprime ton compte Google (Firebase suit automatiquement).
  • Droit d'opposition au traitement : déconnecte-toi de la sync cloud à tout moment (Réglages → Cloud Sync → Se déconnecter).
  • Droit de réclamation : tu peux saisir la CNIL si tu estimes que tes droits ne sont pas respectés.

9. Modifications de la politique

Cette politique peut être mise à jour pour refléter les évolutions de l'app ou de la réglementation. En cas de modification substantielle, nous t'informerons via une notification dans l'app. La date de dernière mise à jour est indiquée en haut de cette page.

Important — Données médicales : APEX Fitness n'est pas un dispositif médical et ne traite aucune donnée de santé au sens du RGPD (art. 9). Les informations que tu saisis (poids, mesures, ressentis d'entraînement) sont des données fitness/bien-être, pas des données médicales. Si tu as une pathologie diagnostiquée, consulte ton médecin avant de suivre nos suggestions.
